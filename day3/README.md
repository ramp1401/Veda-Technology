# Task 2: Conditional Statements for Data Decisions

**Track:** Data Science  
**Level:** Level 1 - Day 2  
**Tools:** Python 3, Jupyter Notebook  

---

## 📌 Project Overview
This repository contains the solution for **Day 2 (Task 2)** of the Data Science Track. The task focuses on mastering Python conditional statements (`if`, `elif`, `else`) and logical operators to classify, validate, and segment structured data.

---

## 📂 Deliverables

- **`Task_2_Conditional_Statements.ipynb`**:
  - **Part 1: 10 Conditional Logic Examples**
    1. Numerical comparison (`>=`) for pass/fail determination.
    2. Categorical exact match (`==`) for department routing.
    3. Multi-tier numerical bucketing (`if-elif-else`) for salary brackets.
    4. Logical `and` operator requiring dual eligibility criteria.
    5. Logical `or` operator for flexible bonus eligibility rules.
    6. Logical `not` operator for identifying unverified profiles.
    7. Nested conditionals for tiered scholarship screening.
    8. List membership (`in`) for regional metro categorization.
    9. Chained range comparison (`35 <= hours <= 45`) for work hours validation.
    10. String validation checking for empty/default values.
  - **Part 2: Applied Classification Programs**
    - **Student Performance Dataset Classification:** Evaluates composite marks and attendance to assign grades (`Distinction`, `Pass`, `Conditional Pass`, `Fail`).
    - **Employee Salary & Appraisal Classification:** Categorizes salary tiers and computes annual performance appraisal actions.

## ⚙️ How to Run the Notebook

1. Ensure Python and Jupyter are installed:
   ```bash
   pip install jupyter
   ```
2. Launch Jupyter Notebook in your workspace directory:
   ```bash
   jupyter notebook
   ```
3. Open `Task_2_Conditional_Statements.ipynb` and run all cells (`Cell > Run All`).
