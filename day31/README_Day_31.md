# Day 31 — Student Performance & Learning Analytics

**Veda Technology · Level 2 · Day 31 · Project 1 of 3**

## Overview
An end-to-end introductory data science project analyzing student academic and learning data.

## Objectives
- Data cleaning and inspection
- Exploratory data analysis
- Attendance and subject-wise analysis
- Correlation analysis
- Feature engineering
- Linear Regression for final-score prediction
- Logistic Regression for pass/fail prediction
- Model evaluation
- Basic student risk analysis

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook, Excel, Git/GitHub.

## Dataset
A synthetic student dataset is generated inside the notebook. It contains attendance, study hours, assignment score, previous score, Math, Science, English, final exam score, and pass/fail status.

## Workflow
1. Create and inspect data
2. Clean duplicates/missing values
3. Perform EDA
4. Analyze subject performance
5. Analyze attendance
6. Build correlation matrix
7. Engineer features
8. Train Linear Regression
9. Train Logistic Regression
10. Evaluate and interpret models
11. Perform basic risk analysis

## Evaluation
**Regression:** MAE, RMSE, R²  
**Classification:** Accuracy, Precision, Recall, F1-score, Confusion Matrix

## Important Note
The dataset is synthetic and intended for learning/portfolio demonstration. It should not be used for real student decisions.
