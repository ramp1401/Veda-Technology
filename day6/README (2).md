# Level 1 - Day 6: List and Dictionary Comprehensions

**Track:** Data Science  
**Task:** Task 6  
**Tools:** Python 3, Jupyter Notebook  

---

## 📌 Project Overview
This repository contains the deliverables for **Task 6 (Data Science Track)**. The objective is to apply concise, optimized Python comprehension syntax (`lists` and `dictionaries`) to clean, filter, and transform structured data arrays.

---

## 📂 Deliverables Included

1. **`Task_6_List_and_Dictionary_Comprehensions.ipynb`**:
   - **Syntax Comparison:** Performance and structural comparison between explicit `for` loops and comprehensions.
   - **5 List Comprehension Examples:**
     1. Numerical scaling and percentage calculations.
     2. Value threshold filtering (`score >= 70`).
     3. String stripping and lowercasing for text preprocessing.
     4. Ternary conditional assignments (`if-else` categorization).
     5. 2D nested list flattening.
   - **4 Dictionary Comprehension Examples:**
     1. Creating dictionaries by pairing parallel iterables (`zip`).
     2. Threshold-based record filtering (`inventory < 15`).
     3. Conditional price categorization (`Premium` vs `Standard`).
     4. Currency transformation calculation.
   - **End-to-End Pipelines on Suggested Datasets:**
     - **Student Marks Dataset:** Average computation and dual-criteria honor roll qualification mapping.
     - **Product Dataset:** In-stock filtering, title standardization, and category-based dynamic price discounting.
2. **`Task_6_List_and_Dictionary_Comprehensions.pdf`**:
   - Executive PDF formatted for submission.
