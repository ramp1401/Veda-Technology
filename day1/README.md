## 🗂️ Notebook Structure

The notebook is organized into a sequence of:

- **Markdown cells** — explanations, headings, and learning notes.
- **Code cells** — Python examples that can be executed and modified.
- **Outputs** — results generated when the code cells are run.

This makes the notebook suitable for learning interactively rather than only reading the material.

## 🛠️ Requirements

You need:

- Python 3.x
- Jupyter Notebook or JupyterLab
- A Python kernel configured for Jupyter

### Install Jupyter

```bash
pip install notebook
```

Or, if you use JupyterLab:

```bash
pip install jupyterlab
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Start Jupyter Notebook:

```bash
jupyter notebook
```

4. Open `Day_1_Python_for_Data_Science.ipynb`.
5. Run the cells from top to bottom using **Shift + Enter**.
6. Experiment with the examples to reinforce the concepts.

## 💡 Recommended Learning Approach

For the best results:

1. Read the explanation before running the code.
2. Run each code cell yourself.
3. Change values and experiment with the examples.
4. Try to predict the output before executing a cell.
5. Add your own small examples after each concept.
6. Review the notebook again after completing all sections.
