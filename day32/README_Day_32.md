# Day 32 — Student Performance & Learning Analytics

**Veda Technology · Project 2 of 3**

## Overview
A beginner-friendly data science project analyzing synthetic student data to explore attendance, study hours, subject-wise scores, and final outcomes.

## Objectives
- Inspect and clean data
- Perform exploratory data analysis (EDA)
- Analyze attendance and subject performance
- Explore numeric correlations
- Engineer useful features
- Predict final scores with Linear Regression
- Predict pass/fail with Logistic Regression
- Evaluate and interpret model results

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook, Git/GitHub.

## Dataset
A reproducible synthetic dataset is generated inside the notebook. It includes attendance, study hours, assignment and previous scores, Math/Science/English scores, final score, and pass/fail status. No download is required.

## Workflow
1. Generate, inspect, and clean the data
2. Visualize score distributions and relationships
3. Compare subject averages and attendance bands
4. Review correlations
5. Engineer features
6. Train and evaluate Linear Regression
7. Train and evaluate Logistic Regression
8. Interpret coefficients and exploratory support flags

## Metrics
- Regression: MAE, RMSE, R²
- Classification: accuracy, precision, recall, F1-score, confusion matrix
