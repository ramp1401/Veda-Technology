## 📌 Project Overview
This repository contains the official deliverables for **Day 12 (Task 12 - Classes and Objects for Data Science)** of the Data Science Internship track.

### 🎯 Objective
Understand Object-Oriented Programming (OOP) fundamentals in Python: defining classes, instantiating objects, instance variables, self, __init__ constructor, and class methods.

---

## 📊 Summary Reference Guide

| OOP Concept | Syntax / Keyword | Data Science Application |
| :--- | :--- | :--- |
| Class Definition | class Student: | Blueprint for entities (models, records, transformers) |
| Constructor | def __init__(self, ...): | State initialization (weights, learning rate, schema) |
| Instance Method | def evaluate(self): | Data transformation, scoring, and calculation operations |
| Self Keyword | self.attribute | Reference to the current object instance |
| Class Attributes | total_records = 0 | Cohort-level counters and global configurations |
